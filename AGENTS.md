# Dice of Petalia

This is the Vite + TypeScript source for the standalone Dice of Petalia game.

Use pnpm via Corepack (`pnpm@10.15.0`).

Before handing off code changes, run the relevant checks:

```sh
corepack pnpm typecheck
corepack pnpm test:run
corepack pnpm build
```

For setup, local development, and deployment details, see [README.md](README.md).
